Controls

Budget cap $5.00 (pipeline `--budget`, enforced by reservations before dispatch) · output-token cap 4096 per call · max workers 1 · max fallback fraction 0.01 · invalid-output retries 1 · transient retries 4 with exponential backoff and jitter.

Concurrency decision: 1 worker. Measured on 2026-10-06 with the same 50 cost_100 reviews: 1 request took ~60 s warm; 3 concurrent requests on a 3-slot Ollama server took 347 s for 150 reviews (2.3 s/review vs 1.2 s/review), so parallel slots are slower on this 8 GB M1.

API spend vs. other costs

The default configuration runs every model role on a local Ollama model, so measured API spend is $0. That is not the same as free: local inference uses this laptop's time, memory and electricity. Electricity is estimated from the editable local_compute assumptions; hardware wear is unknown and not priced. Roles switched to Anthropic in config/pipeline.json are billed from provider-reported usage x cost/rates.csv. Hardware wear and the owner's time are not priced (unknown)."}

Formulas

`item_cost = billed_units x price_per_unit` per call and billing item (see `usage.csv`); projections scale each stage by its own work count: enrichment by distinct texts and requests (ceil(texts/batch_size)), verification by sampled texts, fallback by capped items, group by issue count and memo once. Local electricity = local hours x watts / 1000 x USD per kWh (assumptions).
